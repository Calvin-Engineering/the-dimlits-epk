# The Dimlits — Modern EPK

This is an updated, more modern Electronic Press Kit for The Dimlits.

## What's new
- More polished, modern visual design
- Large hero area intended for a full-width band photo
- Band members section designed for individual member photos and bios
- Press-kit bio added to the About section
- Rough logo included in the header/site branding
- Responsive layout for desktop and mobile

## Replace with your real photos
Swap these placeholder files with your real images while keeping the same filenames, or update the HTML paths:

- `assets/hero-band.svg` → replace with your curb-sitting band shot
- `assets/member-1.svg`
- `assets/member-2.svg`
- `assets/member-3.svg`
- `assets/member-4.svg`

## Edit in index.html
Search for these placeholders and replace them:
- `Member Name`
- member roles
- `booking@thedimlits.com`
- `href="#"`

## Run locally
You can open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then go to `http://localhost:8000`.
